# πρέσβυς (presbys)

> **πρέσβυς**，古希腊语「长者；最年长而仍屹立者」。

零依赖小工具：拉取 [openctp](http://www.openctp.cn/dc_instruments.html) 的**在市期货合约**快照，找出每个品种最年长（上市日最早）的在市合约，量它到今天已存在多少自然日。

它回答一个实际问题：**自己合成期货主力连续合约时，如果不下载已到期/退市合约的历史数据，最远能回溯多久？**

**在线结果：<https://wyndream.github.io/presbys/>**（由 GitHub Pages 托管，刷新方式见「发布」节）

## 结论速览（2026-09-28 快照）

- 90 个品种中，**80 个不足 1 年**；≥1 年 9 个；≥2 年只有 `sc`（1032 天）；**没有任何品种达到 3 年**。
- 这个统计量的本质是交易所的**挂牌提前期**：多数商品期货只提前约 12 个月挂最远月合约，INE 原油 `sc` 挂得最远（约 34 个月），中金所只挂近月加两个季月（约 5 个月）。
- 推论：要 3 年以上的真实主力连续序列，到期合约的历史数据不可避免。

## 使用

```bash
./presbys.sh                          # 拉取当日快照 → out/ 下生成全部产物
./presbys.sh --as-of 2026-09-28       # 指定天数计算终点（默认今天）
./presbys.sh --out docs               # 换输出目录
./presbys.sh --input snapshot.json    # 复用已有快照，离线模式
```

依赖仅 `bash` / `curl` / `jq` / `awk`。

## 发布

网页（GitHub Pages，源＝main 分支 `docs/`）由 Actions 一键发布：**Actions → publish → Run workflow**。流程＝云端复跑脚本刷新 `docs/` → 数据有变化才提交推回 main → Pages 自动部署；无变化则跳过，不刷历史。本地验证可用 `./presbys.sh --out docs`，但不要直接提交 `docs/`——它是发布产物，下次发布会覆盖手改。

## 输出

| 文件 | 内容 |
|------|------|
| `index.html` | 汇总表的网页渲染（概览卡片 + 可筛选表格） |
| `presbys_products.csv` | 品种级汇总：品种、交易所、在市合约数、最早合约、上市日、已存在天数、覆盖档 |
| `presbys_contracts.csv` | 全量在市合约清单（含各合约上市日/到期日/乘数） |
| `snapshot_<日期>.json` | API 原始快照 |

## 口径

- 品种＝`ProductID`；最早合约＝该品种在市合约中 `OpenDate` 最小者（并列取 `ExpireDate` 最近者）。
- 天数＝`OpenDate` → as-of 日期的自然日差。
- 覆盖档阈值：365 / 730 / 1095 / 1825 天 ↔ ≥1y / ≥2y / ≥3y / ≥5y。
- 接口返回天然只含在市合约（`InstLifePhase='1'`），不含已退市合约。

## 注意

- `*_f`（如 `l_f`）是大商所月均价期货，与同名标准合约是不同品种，勿混用。
- `ZC`（动力煤）虽在市，但已长期无成交，覆盖天数对它无意义。
- 数据为当日快照，交易所盘中挂新合约后口径随之变化；复跑即得最新结果。
